# The Harness

A Claude Code plugin, part of PreviouslyUpcoming. It scores every task for complexity, runs it on the model that score calls for, gates commits on an independent eval, and writes a metadata stream that PU ingests and visualises.

Nothing is built yet. Start with:

- [docs/PLAN.md](docs/PLAN.md): the plan, milestones M1–M7, design changes C1–C16, and what we won't build.
- [docs/spikes.md](docs/spikes.md): the day-1 checks of the Claude Code behaviour the design depends on.
